ONE-PAGE WEBSITE ASSIGNMENT

Main file:
- one_page_website.html

Supporting files:
- styles.css
- images/toronto.svg
- images/mountains.svg
- images/niagara.svg

How to open:
1. Extract the ZIP folder.
2. Keep all files and folders together.
3. Double-click one_page_website.html.
4. The page will open in your web browser.

Included requirements:
- Home section with headings and paragraphs
- Picture section using local <img> tags
- Contact form using <form>, <input>, <select>, and <textarea>
- Video section using an <iframe>
- Footer
- Navigation using HTML bookmarks
- Separate CSS file for future enhancement

Note:
The form is a front-end demonstration and does not send data to a server.
The embedded video requires an internet connection.
