CSS Effects Challenge

Files:
- index.html
- style.css
- images/image1.jpg
- images/image2.jpg
- images/image3.jpg

How to use:
1. Extract the ZIP file.
2. Keep all files and folders in the same structure.
3. Open index.html in a web browser.
4. Move the mouse over the images to see the hover effects.

The project uses the Google Font 'Poppins' through a link in the HTML <head>.
